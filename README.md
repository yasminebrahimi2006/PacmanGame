*** Pac-Man (بازی پک‌من) - پیاده‌سازی با جاوا ***

یک پیاده‌سازی ساده و کلاسیک از بازی پک‌من با استفاده از زبان java و کتابخانه‌ی Swing. این پروژه شامل حرکت پک‌من با کلیدهای جهت‌نما، اشباح با حرکت تصادفی، سیستم امتیازدهی، ذخیره‌سازی امتیاز برتر و افکت‌های صوتی است.



(Features) 

- کنترل پک‌من با کلیدهای **Up / Down / Left / Rigth**.
- اشباح هوشمند با حرکت تصادفی و جلوگیری از بازگشت به مسیر قبلی.
- سیستم امتیازدهی پویا (۱۰ امتیاز برای هر نقطه، ۵۰۰ امتیاز جایزه برای برنده شدن).
- ذخیره‌سازی امتیاز برتر در فایل `highscore.txt` (حتی پس از بستن بازی).
- دکمه‌ی Play Again برای شروع مجدد بدون نیاز به بستن پنجره.
- افکت‌های صوتی برای رویدادهای شروع بازی، خوردن نقطه، برد و باخت.
- رابط کاربری گرافیکی با استفاده از تصاویر برای پک‌من و اشباح.

---

 (Requirements & Environment)

زبان برنامه‌نویسی =  Java (نسخهٔ ۱۱ یا بالاتر - کاملاً با Java 8 نیز سازگار است) |
کتابخانه‌های موردنیاز =  **هیچ کتابخانه‌ی خارجی‌ای نیاز نیست** (فقط Java SE + Swing) |
سیستم‌عامل = ویندوز، لینوکس، مک‌اواس (هر سیستم‌عامل دارای JVM) |
IDE پیشنهادی =  IntelliJ IDEA، Eclipse، NetBeans یا VS Code (با افزونه‌ی Java) |
ابزار ساخت =  پروژه به صورت خام با `javac` کامپایل می‌شود

 *توجه*برای پخش صدا، سیستم‌عامل باید از فرمت WAV پشتیبانی کند
